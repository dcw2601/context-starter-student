# memory/ — 助手的记忆

**会话一关，助手就把这次的事全忘了。只有写进这个文件夹的东西留得下来。**

这是整套系统里最容易被忽略、但决定它有没有用的一层。
没有记忆，每次都是从「你哪科弱？」重新问起，等于每次从零开始。
有记忆，助手可以直接说「上次你移项的符号老错，今天先来一道试试」。

## 怎么用

一个事实 / 一个教训 = 一个文件。写完在 `MEMORY.md` 里加一行指针。

```markdown
---
name: math-linear-equations
description: 一元一次方程的进度和卡点
type: progress
---

## 2026-09-08
- 卡点：移项时符号没变（计算层，不是概念层）
- 有效讲法：不跳步，每次写「两边同时减 3x」
- 状态：初步过关，**待 9/9 回测**
```

`type` 用这四种：

| type | 放什么 |
|---|---|
| `progress` | 某一科/某个知识点学到哪了、卡在哪 |
| `method` | 什么讲法对他管用、什么没用 —— **这类最值钱** |
| `plan` | 考试时间、目标、这周要干什么 |
| `reference` | 课本章节、老师给的资料、有用的网站 |

## 规矩

- **`MEMORY.md` 只放一行指针，不放内容。** 它每次会话都会被完整加载，写胖了会挤占空间。
- **已经不对的记忆要删掉。** 三个月前「他数学很弱」现在可能已经不成立了，
  留着会让助手按错的难度出题。
- **别记会话结束就没用的东西**（今天做的这道题的数字是多少）。
- **状态要写实。** 没过关就写「未过关」。写「已掌握」骗的是下一次的自己。
- **不要写真名、学校、住址。** 如果这个文件夹会放到公开的 GitHub 上，这条是底线。
