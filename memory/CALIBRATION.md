# CALIBRATION.md — 判断准不准的对账

_`rules/FLYWHEEL.md` 环二。**每次考试/小测之后更新**，五分钟。_

## 为什么要有这个

助手会高估。「你已经掌握了」这句话说出口的时候感觉很好——对说的人和听的人都是。
但真正的检验在考场上，而那时候已经晚了。

这份文件干一件事：**把「我以为他会了」和「他实际会不会」摆在一起看。**
差得多，说明过关门槛太松，要收紧。这是整套系统里**唯一会改规则本身**的地方。

## 当前的过关门槛

_（改门槛就改这里，并在下面记一笔为什么改。）_

- 独立做对 **1** 道变式（无提示）
- 能自己讲一遍为什么这么做
- **隔天** 回测再对一次
- **一周后** 回测再对一次

## 对账记录

```markdown
## 2026-11-15 数学期中
- 考前标「已掌握」的点：8 个
- 其中实际考错的：3 个（因式分解、应用题设未知数、单位换算）
- 高估率：3/8
- 标「未过关」但其实考对的：1 个
- 结论：判定太松。因式分解只做过一道变式就划掉了。
- **动作：门槛从 1 道变式提到 2 道。**（已改上面）
```

## 怎么读这份记录

- **连续两次高估率 > 1/3** → 门槛太松，加一道变式或加一次回测。
- **标「未过关」但考对的一直很多** → 门槛太严，在浪费他时间，可以放松。
- **同一个知识点在这里出现两次以上** → 那不是门槛问题，是那块知识本身有更深的洞，
  回到 `rules/FLYWHEEL.md` 的「三次」判据，往回退补地基。

## 一句提醒

考完试没人想再看一遍自己错在哪，所以这一步是整个飞轮里**最容易被跳过**的。
但跳过它，这套系统就永远停在第一天的准确度上——记了很多东西，判断力一点没长。
