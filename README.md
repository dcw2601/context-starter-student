# 学习助手骨架（Study Companion Starter）

给中学生用的 AI 学习助手配置骨架，配合 [Claude Code](https://claude.com/claude-code) 使用。

**它跟直接问 AI 的区别只有一条：它不给你答案，它把你教到会。**

---

## 这是什么

一堆 Markdown 文件。没有代码，没有要装的东西，不用会编程。

Claude Code 每次启动会自动读 `CLAUDE.md`，那份文件又会带上「你是谁」「怎么教」
「不许编造」这几份规则。于是同一个 AI，行为完全不一样了：

| | 直接问 AI | 装了这个骨架 |
|---|---|---|
| 「这道数学题怎么做」 | 给出完整解题过程 | 先问你卡在哪，再一级一级给提示，直到你自己做出来 |
| 「帮我写篇作文」 | 写一篇给你 | 看你写的，指出结构问题，你改，它再看 |
| 不确定的知识 | 编一个听起来很对的 | 说「我不知道」，告诉你去哪查 |
| 你说「你错了」 | 立刻道歉改口 | 重新检查；你给了新证据才改，光是不高兴不改 |
| 下次再来 | 从头问一遍你哪科弱 | 记得你上次卡在哪，直接接着上次 |

## 怎么用

1. 装 [Claude Code](https://docs.claude.com/en/docs/claude-code)。
2. 下载这个文件夹（Code → Download ZIP，或者 `git clone`）。
3. **改 `rules/USER.md`** —— 填年级、哪科弱、具体卡在哪、什么讲法对你管用。
   这一步别跳过，也别美化：写「数学还行」而实际不行，它会按「还行」的难度出题，
   结果是你一直做不出来。
4. 在这个文件夹里运行 `claude`，开始用。

就这样。第 3 步花十分钟，是整个过程里唯一需要动脑的地方，也是效果差别最大的地方。

## 里面有什么

```
CLAUDE.md              总入口，Claude Code 每次自动读
rules/
  SOUL.md              助手是谁：教练，不是答案机器
  USER.md              你是谁 ← 你要改的就是这个
  EPISTEMICS.md        不许编、不许因为你不高兴就改口
  TEACHING.md          怎么教：提示分级 + 五步循环 + 什么算代写
  skills/INDEX.md      助手会做什么，以及怎么自己加新的
.claude/skills/
  mistake-book/        错题本
  concept-ladder/      讲懂一个新概念
  essay-review/        作文批改
memory/
  MEMORY.md            助手记住的事（索引）
  README.md            怎么写记忆
```

最值得读的是 **`rules/TEACHING.md`** —— 提示分五级、一级一级给，
以及「什么算代写、什么不算」的对照表。整套东西的核心在那份文件里。

## 关于「不代写作业」

这是最高优先级的规则，写在 `CLAUDE.md` 和 `rules/TEACHING.md` 里。判断标准一句话：
**能直接抄进作业本的，它不给。**

要说清楚的是：**这是写在提示词里的规则，不是技术上的锁。**
一个铁了心要作弊的人，换个窗口问同一个 AI 就绕过去了。

所以这份骨架不是防作弊工具，它是给**想真的学会**的人用的 ——
让 AI 从一个交作业的捷径，变成一个有耐心的教练。它挡不住不想学的人，也不打算挡。

另外，`memory/` 会记录进度和卡点。如果家长和孩子一起用，
这份记录可以是聊学习的素材；但**不要把它变成监视**。
一个知道自己每句话都会被记下来给家长看的孩子，会开始说假话，这套东西就废了。

## 隐私

`rules/USER.md` 和 `memory/` 里**不要写真名、学校、住址、班级、生日、联系方式**。
助手需要的是「中一、数学弱、喜欢用类比理解」，不是身份信息。用个代号就够了。

打算把自己改过的版本传到公开 GitHub 上之前，**把这两处再看一遍**。

## 自己往下长

三个 skill 是起点。用一阵子你会发现还缺点什么 —— 考前复习计划、单词本、
实验报告怎么写 —— `rules/skills/INDEX.md` 末尾写了怎么加。

这才是这套东西真正的用法：**它是个骨架，不是成品。**
